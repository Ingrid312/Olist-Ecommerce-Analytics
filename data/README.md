# Public Olist source data / 原始数据说明

Download the public dataset from https://www.kaggle.com/datasets/olistbr/brazilian-ecommerce and place these files in this `data/` folder:

- `olist_customers_dataset.csv`
- `olist_orders_dataset.csv`
- `olist_order_items_dataset.csv`
- `olist_order_payments_dataset.csv`
- `olist_order_reviews_dataset.csv`
- `olist_products_dataset.csv`
- `product_category_name_translation.csv`

The raw datasets are **not redistributed** in this repository. Notebook cells load them locally into SQLite (in memory).
